# AI 사서 보조 싱글 에이전트

LangChain과 Ollama를 활용하여 도서 검색과 도서관 이용을 지원하는 실습용 에이전트입니다.

## 수업 코드 활용

수업에서 제공한 project_4/05_full_agent.py를 기반으로 구현했습니다.

- create_agent를 이용한 싱글 에이전트 구성

- @tool 기반 업무 도구

- Runtime Context와 미들웨어를 통한 사서 정보 주입

- before_agent 기반 입력 가드레일

- after_agent와 Judge 모델을 이용한 최종 답변 검수

- InMemorySaver를 이용한 단기 기억

- InMemoryStore와 ToolRuntime을 이용한 장기 기억

- UUID를 이용한 Append 방식의 이용자 정보 저장

이메일 상담용 도구와 정책을 사서 업무에 맞게 변경했습니다.

도구 결과를 검수 근거로 전달하고, 대출 도구 호출 누락과 후속 질문의 검수 문제를 보완했습니다.

## 주요 기능

- 제공된 도서 11권의 제목·저자 검색

- 검색 결과가 없는 경우 안내

- 실습용 가상 대출 상태 확인

- 이용자 회신 초안 작성

- 사서 이름·역할 반영

- 도서관 업무와 무관한 요청 차단

- 타인의 비공개 대출 정보 요청 차단

- 같은 대화에서 후속 질문 처리

- 이용자 선호 저장 및 새 대화에서 조회

- 확인되지 않은 정보에 대한 최종 답변 검수

## 실행 환경

Python 3.12.10과 Ollama를 사용했습니다.

패키지 버전은 requirements.txt에 기록했습니다.

## 파일 위치

구현 코드, 패키지 목록, 상세 안내는 [github_upload](github_upload/) 폴더에 있습니다.

## 설치 및 실행

Windows PowerShell 기준입니다.

Ollama를 설치하고 실행한 상태에서 진행합니다.

```powershell
cd github_upload

ollama pull qwen3:4b-instruct-2507-q4_K_M

python -m venv .venv

.\.venv\Scripts\python.exe -m pip install -r requirements.txt

.\.venv\Scripts\python.exe .\05_full_agent.py

```

## 사용 예시

- 서정욱 작가의 책을 찾아줘.

- 그 책의 저자가 누구야?

- 시간을 파는 서점은 대출 가능해?

- 해리 포터라는 책을 찾아줘.

- 나는 짧은 답변을 선호해. 저장해줘.

- 내가 저장한 응답 선호를 알려줘.

## 대화 명령어

- /new: 새 대화 시작. 저장된 이용자 정보는 유지됩니다.

- /quit: 프로그램 종료. 모든 기억이 초기화됩니다.

## 데이터 및 구현 범위

도서 제목과 저자는 과제에서 제공한 목록입니다.

대출 상태는 테스트를 위해 정의한 실습용 가상 데이터입니다.

외부 도서관 API와 별도의 RAG 시스템은 사용하지 않습니다.

이용자 회신은 초안 작성이며 실제 이메일을 발송하지 않습니다.

## 한계

- 기억은 프로세스 메모리에 저장되어 프로그램 종료 시 사라집니다.

- 키워드 기반 입력 차단은 표현이 달라지면 놓칠 수 있습니다.

- 모델의 도구 선택과 Judge 판정은 항상 정확하지 않습니다.

- 장기 기억은 Append 방식이므로 선호가 변경되면 여러 기록이 남습니다.

- 실제 서비스의 이용자 인증과 영구 저장은 구현하지 않았습니다.
